## 📝 Descripción del proyecto

Este proyecto consiste en el desarrollo de **dos páginas web**:

1. Una **tarjeta de presentación** personal con temática *libre*.
2. Una sección adicional donde se amplía la información profesional y personal.

El objetivo fue aplicar los conceptos fundamentales de maquetación web vistos en clase, dándole un enfoque creativo y técnico.

---

## 🧠 Conceptos aplicados

- ✅ Estructura correcta de archivos HTML semánticos.
- ✅ Organización de carpetas (assets, styles, pages, etc.).
- ✅ Uso de CSS para estilizado, diseño responsive y efectos visuales.
- ✅ Implementación de recursos generados por IA (imagen de fondo, certificados y textos).

---

## 🎨 Diseño y personalización

> Todo el diseño visual, la disposición de los elementos y la elección de estilos fueron **100% creación propia**.

La identidad visual busca reflejar el espíritu del mundo de la ciberseguridad: oscuridad, tecnología y precisión.

---

## 🤖 Recursos generados por IA

- Imagen de fondo  
- Textos de contenido  
- Certificados mostrados en la sección "más información"

Esto permitió agilizar el proceso creativo y enfocarme en la estructura y el estilo.
